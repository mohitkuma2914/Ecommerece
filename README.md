# E-Commerce Backend Application

A Spring Boot based E-Commerce Backend Application that provides REST APIs for managing customers, sellers, products, carts, and orders.

## Features

- Customer Management
- Seller Management
- Product Management
- Cart Functionality
- Order Placement
- RESTful APIs
- Layered Architecture
- DTO Implementation
- Exception Handling
- Database Integration using MySQL
- Spring Data JPA

---

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Lombok
